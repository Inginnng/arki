# Arki · 一览 0.3.0

Arki 的首个公开版本：把项目源码整理成可继续阅读的架构文档、组件图与典型流程。

## 主要功能

- 在同一嵌套组件图上切换典型场景，查看参与者、数据传递、输入、处理与输出。
- 点击组件、子系统、步骤或连线提问，沿着代码证据核对和完善分析。
- 支持条件分支、重复参与、并行、合流、返回与重试；离线导出保留所有场景。
- 独立文档工作台、项目存档恢复、撤销/重做和离线阅读。
- 新增手动检查更新、版本说明和官方下载入口；不会自动安装或重启。

## 安装

下载 `arki-0.3.0.zip`，按 `SHA256SUMS.txt` 核对哈希并解压。需要 Node.js 20.19+ 和已登录的 Codex；发行包无需安装项目依赖。

在解压目录运行 `node dist/arki.mjs --root "你的项目目录" --open`，或在 Windows 将项目文件夹拖到 `Arki.cmd`。

## 已知边界

Windows 是主要实测桌面环境。AI 请求使用你的 Codex 服务和额度，会发送选定代码片段；本地运行不等于离线推理。架构工作台使用项目证据，不声称精确继承当前 Codex 任务。没有自动安装器，也没有一般模型准确率保证。

浏览器存档按项目及站点地址保存，重要分析请导出。升级时结束旧后台，从新目录启动同一项目和端口，再刷新页面。

使用方法、测试范围与后续方向见仓库的快速开始、能力报告和路线图。
