情况处理
名称太长 / 标签拥挤换行、增高、编号索引；全文留在详情。接受分析。
缺失归属 / 归属成环移到“待归属”，标明原因；不猜测父级。
一条边引用不存在的步骤隔离该边，保留其原文和诊断；有效部分照常展示。
布局算法失败架构回退分组目录；流程回退步骤列表与分支说明。
证据不足 / 来源发生变化不得标为已确认；保留草稿与旧版，定向补读。
越权读取 / 写入 / 敏感路径阻止相应动作；不能用“容错”绕过边界。
