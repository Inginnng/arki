# 中文侧边问答测试文档

这份文档供你手动测试“选中文字 → 提问 → 查看回答和证据”。下面的示例不是后端预置答案，也不代表任何测试已经通过。

## 怎么开始

1. 刷新网页，在左侧找到「中文侧边问答测试文档」。
2. 在正文上方「选择 Codex 任务」中，明确选择你想引用讨论背景的任务。
3. 拖选下面某个词或句子，直接在选词附近出现的小框中输入建议问题，再点击「提交问题」。不想提问时，点击正文其他位置或按 Escape，小框会消失，不留空胶囊。
4. 观察回答是否切题，项目事实是否有来源，未知事项是否被明确说明。

界面与提交逻辑依据：`apps/reader-ui/src/InlineSideReader.tsx:251`、`apps/reader-ui/src/InlineSideReader.tsx:211`。

注意：提交问题会通过本机 Codex 调用模型服务；可能发送选区、相关项目证据和所选任务的讨论片段。仅阅读本文件不会自动提交问题。调用依据：`packages/workspace-server/src/side-question-service.ts:61`、`packages/app-server-bridge/src/local-side-runtime.ts:370`。

## 测试一：能不能真正解释术语

可选原文：

> 我在技术文档中看到了 MCP、JSON 和 API，但不清楚它们分别解决什么问题。

先只选中 **MCP**，提问：

> MCP 是什么？请用中文解释，再用一个生活中的例子帮助我理解。先讲概念，不要把这个例子说成项目已经实现的功能。

然后只选中 **JSON**，提问：

> JSON 是什么？请给一个包含姓名、年龄和兴趣列表的小例子，并解释其中的符号。

观察：两次回答应该针对不同术语展开；只重复“这段内容描述了完整流程”并不算解释。这里没有预先给出概念答案，方便你看模型是否真的在回答。

## 测试二：能不能读懂决定的变更

以下完全是虚构阅读材料，不是 AIMD 的真实业务配置：

> 青禾书店最初计划每次配送 40 本书。后来配送车的容量调整为 30 本，店长决定为临时订单预留 6 本的空间，因此把常规配送批次改为 24 本。旧的 40 本方案不再使用。书店还没有决定使用哪一家快递公司。

选中整个段落，提问：

> 现在每批应该配送多少本？为什么不是原来的数量？快递公司确定了吗？请区分已经决定的事情和仍然未知的事情。

观察：回答是否识别新决定覆盖旧决定，是否解释预留空间，而不是凭空补出一家快递公司。

这个测试只验证对当前选区的理解，不能证明读取了 Codex 任务历史，因为材料已经写在本文中。

## 测试三：能不能结合真实代码解释

可选原文：

> 侧边问答服务通过 documentHash 检查浏览器中的文档是否仍然有效；模型回答后，还会再次核对原始文档和本次提供的证据。

当前代码依据：`packages/workspace-server/src/side-question-service.ts:22`、`packages/workspace-server/src/side-question-service.ts:72`、`packages/workspace-server/src/side-question-service.ts:77`。

选中上面这句话，提问：

> documentHash 在这里起什么作用？为什么提问前检查一次还不够？请结合实际代码给出文件路径和行号。如果当前检索没有找到实现，请直接说明证据不足。

观察：回答是否解释“生成回答期间文件也可能变化”，引用是否真的支持该结论；不要仅凭本文中的说明就认定代码已经被核验。

## 测试四：引用核验是不是正确性保证

可选原文：

> 引用位置已核验，不等于回答已经经过独立语义审核。

当前界面使用上述能力区分，并明确限制新侧聊流程的审核和保存能力。依据：`apps/reader-ui/src/InlineSideReader.tsx:78`、`apps/reader-ui/src/InlineSideReader.tsx:255`。

建议提问：

> 引用存在，为什么还不能保证回答正确？如果模型引用了一个真实文件，但那个文件并不能支持结论，应该如何判断？

观察：回答是否区分“引用存在”和“引用支持结论”，有没有错误地宣称本次已通过独立审核。

## 测试五：有没有用到所选任务的讨论

可选原文：

> 我想利用此前讨论过的背景理解项目，而不只是逐句解释眼前的文档。

选中这句话，提问：

> 根据我选择的 Codex 任务，概括其中最近明确提出的一项需求和一项尚未完成的工作。请把任务讨论与当前代码事实分开；如果相关讨论没有进入本次上下文，就说明无法确认。

观察：请与你自己知道的那项任务内容对照。本文件没有提供这道题的标准答案；回答必须来自真正取得的讨论片段，不能从任务标题猜测。

## 测试六：取消与切换

提交一个问题后，可以尝试点击「取消提问」，或立即切换文档、重新选择任务。观察旧答案有没有错误地出现在新页面下。

相关实现：`apps/reader-ui/src/InlineSideReader.tsx:120`、`apps/reader-ui/src/InlineSideReader.tsx:121`、`apps/reader-ui/src/App.tsx:477`。
